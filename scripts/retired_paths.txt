# Retired paths — files deleted on purpose, which must stay gone.

# One repo-relative path per line; `#` starts a comment. A path may declare
# shorthand terms after `;` (comma-separated) — prose names a compose by
# shorthand (`ghcr.yml` for `docker-compose.ghcr.yml`) and the gate cannot
# see a shorthand the list does not declare. Declared, never derived: a
# derived stem would give `docker-compose.ci.yml` the alias `ci.yml`, which
# is a real file (.github/workflows/ci.yml). A line ending in `/` is a
# directory entry: text naming anything under it flags.
# scripts/test_retired_paths.py fails (a) when a listed path exists again, and
# (b) when a LIVING doc, workflow, hook, script or test names a listed path
# (by path, by basename, or by a declared term). Records keep their
# references: the plan/spec/program-record/archive trees (docs/plans/,
# docs/superpowers/, docs/vss-integration/, docs/uplevel/, docs/archive/,
# archive/), goal prompts, and — in .py files only — a line carrying a dated
# decision-log tag like [V 2026-09-28]. Markdown gets no tag exemption: a
# prose record is a tree above, not a dated line. See the checker's docstring
# for the full rule set.
