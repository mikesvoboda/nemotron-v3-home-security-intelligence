## Equivalence notes (why EQUIVALENT survives correctly)

- `rstrip("/") -> rstrip("XX/XX")`: strip-set {'X','/'} on a real URL without trailing X is identical to {'/'}; the URL-building tests use realistic hosts so behavior is unchanged. **Not a bug** — 4 mutants.
- `getattr(settings, "use_ai_gateway", False) -> None/True` default: `use_ai_gateway` is a declared pydantic field with default False (`backend/core/config.py:1315`), so the getattr default is dead code. 2 mutants.
- logger arg->None / message XX-swaps (47 mutants): observable only through caplog; no test pins log text on this module. Treated EQUIVALENT per WP4.4 convention (pure message text).
- `_check_circuit_breaker__mutmut_1/2` produce identical content to the def-line region (def-line noise in AST diff): genuine no-ops.
- `decode("utf-8")->"UTF-8"` case-insensitive codec name: equivalent (inside ENC cluster; counted TEST-GAP with its cluster).
