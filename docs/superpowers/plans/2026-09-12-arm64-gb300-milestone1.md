# arm64/GB300 Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the CPU-core stack of the prod compose file online on the aarch64/GB300 host and make `./scripts/validate.sh` pass, strictly additively.

**Architecture:** Additive overlay — new `config/docker-compose.gb300.yml` + generated `.env` (via the repo's own `setup.py` functions with two host deltas applied) + a two-phase bring-up (`--no-deps` for backend/frontend) that excludes GPU services without touching `docker-compose.prod.yml`. Podman installed per repo convention; Docker coexists and stays untouched.

**Tech Stack:** podman + compose provider (identity discovered by probe P2), podman-compose 1.0.6 (apt), Ubuntu 24.04 aarch64, 64 KiB-page kernel, GB300 sm_103 (unused in M1), uv/Python 3.14, node 20+/npm, vitest, podman socket (rootless).

**Spec:** `docs/superpowers/specs/2026-09-12-arm64-gb300-milestone1-design.md` (read it first; this plan argues from it)

## Global Constraints

- `docker-compose.prod.yml` is NOT modified. Planned shared-file changes are exactly two: `.env.example` four variables (spec §3.3) and evidence-backed `scripts/validate.sh` tooling fixes from Task 7's pre-authorized set (each = focused test + ledger row); anything broader escalates to owner.
- Never touch the co-resident `dgx-inference-*` containers; port 8000 is theirs.
- Never migrate GPU-arch caches: `triton-kernel-cache`, `llama-cache`, `llama-nv-cache`, `AI_MODELS_PATH/triton` (arch-keyed; M2 concern, recorded only).
- All image builds `--no-cache` (CLAUDE.md rule); M1 builds only `backend` + `frontend` images.
- Every commit conventional-commit format (commitlint hook); never bypass pre-commit hooks.
- Ports come from `.env` only (`127.0.0.1:` binding convention preserved).
- Services never in M1: `ai-llm`, `ai-llm-vllm`, `ai-gateway`, `dcgm-exporter`.
- Probe/install results land in the ledger `docs/plans/2026-09-12-context-map-doc-updates.md` with dates.
- Kernel/page size NOT touched (spec §2 decision 4; R3 reversal criteria govern).

**Phase A service list (Tasks 5):** `postgres redis go2rtc foscam-init prometheus grafana loki tempo alloy alertmanager pyroscope node-exporter redis-exporter json-exporter blackbox-exporter`
**Phase B service list (Task 6):** `backend frontend` (started with `--no-deps`)
