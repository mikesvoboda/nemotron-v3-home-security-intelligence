# Accessibility

Nemotron Home Security aims to meet WCAG 2.1 AA compliance standards across all dashboard interfaces.

## Keyboard Navigation

All primary dashboard functions are accessible via keyboard:

- **Tab / Shift+Tab** -- move focus between interactive elements
- **Enter / Space** -- activate buttons and controls
- **Escape** -- close modals and dismiss notifications
- See [Keyboard Shortcuts](keyboard-shortcuts.md) for the full shortcut reference

## Screen Reader Support

Dashboard components use semantic HTML and ARIA attributes to provide meaningful labels for assistive technology.

## Color and Contrast

Risk-level indicators use both color and iconography so that information is not conveyed by color alone. Text meets minimum contrast ratios specified by WCAG 2.1 AA.
