### Recording Rules (monitoring/prometheus-rules.yml)

These pre-compute SLI/SLO metrics:

- `hsi:api_availability:ratio_rate30d` - 30-day API availability
- `hsi:detection_latency:p95_5m` - 5-minute P95 detection latency
- `hsi:analysis_latency:p95_5m` - 5-minute P95 analysis latency
- `hsi:error_budget:api_availability_remaining` - API error budget remaining
- `hsi:burn_rate:api_availability_1h` - 1-hour burn rate
- `job:service_cpu_regression_ratio:5m_vs_24h` - CPU regression detection
- `job:service_memory_regression_ratio:current_vs_6h` - Memory regression detection

## Changes Made (NEM-4153)

### Fixed PromQL Queries

1. **video-analytics.json**

   - Fixed histogram_quantile queries missing rate() aggregation for Re-ID latency
   - Fixed avg(hsi_track_duration_seconds) to use rate sum/count pattern

2. **ai-services.json**

   - Fixed action confidence distribution to use enrichment metrics
   - Fixed action false positive rate to use enrichment metrics
   - Fixed cold start latency to use enrichment_model_load_time_seconds
   - Fixed model restarts to use hsi_pipeline_worker_restarts_total

3. **analytics.json**

   - Added [PENDING] markers to sections with unimplemented metrics (RUM, Database, A/B Testing)
   - Fixed LLM cost metrics to use existing hsi_daily_cost_usd, hsi_estimated_cost_usd_total
   - Fixed budget utilization to use hsi_budget_utilization_ratio
   - Fixed Redis pool metrics to use hsi_redis_pool_in_use, hsi_redis_pool_size

4. **tracing.json**

   - Fixed hsi_http_requests_total to use http_request_duration_seconds_count
   - Fixed hsi_http_request_duration_seconds_bucket to http_request_duration_seconds_bucket

5. **prometheus-rules.yml**
   - Added note referencing profiling-recording-rules.yml for regression detection rules
